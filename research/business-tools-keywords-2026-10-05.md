# Business tools: search intent and implementation

Research date: 5 October 2026. Audience: business owners and founders commissioning website changes, migrations, dashboards or integrations, including UK/London and US teams.

## Keyword mapping

| Page | Primary intent | Supporting terms | Client connection |
| --- | --- | --- | --- |
| `/tools/website-feedback-tool/` | website feedback tool | website redesign feedback, screenshot annotation tool, annotate website screenshot, website redesign brief | A visitor already planning website changes can discuss implementation. |
| `/tools/csv-cleaner/` | CSV cleaner | CSV validator, remove duplicate rows from CSV, CSV import checker, fix inconsistent CSV columns, remove blank CSV rows | A visitor preparing business data can discuss an import workflow, dashboard or integration. |

These are qualitative search-result findings, not measured monthly volumes or Google Keyword Planner forecasts. No Keyword Planner or Search Console account was available. No traffic or ranking forecast is claimed. One substantial page serves each primary task; no thin London/US copies are created. Geographic service availability is stated accurately in each contact section.

## Sources and observations

- [Marker.io website design feedback](https://marker.io/website-design-feedback): a first-party product page uses visual feedback and screenshot annotations for website reviews. This supports the task vocabulary, not demand estimates.
- [IMReviewHQ screenshot annotator](https://imreviewhq.com/website-screenshot-annotator/): a first-party tool page targets screenshot annotation and feedback with a local processing workflow.
- [KIVO CSV cleaner](https://kivotool.com/en/data/csv-cleaner): a first-party page groups whitespace trimming, blank rows, duplicates and delimiters under CSV cleanup.
- [ToolkitBay CSV validator](https://toolkitbay.com/tools/validator/csv-validator): a first-party validator page discusses quoted fields, headers and record width. This supports structural checking as a distinct user task.
- [Google Search Central: AI features](https://developers.google.com/search/docs/appearance/ai-features): AI Overviews and AI Mode use established SEO fundamentals. Pages need discoverable links, crawlable useful text and structured data consistent with that text. No special AI schema or AI text file is required; indexing and inclusion are not guaranteed.
- [RFC 4180](https://www.rfc-editor.org/rfc/rfc4180): parsing reference for quoted commas, escaped quotes and multiline CSV fields. The tool also supports explicit alternative delimiters.
- [OWASP CSV injection](https://owasp.org/www-community/attacks/CSV_Injection): reference for warning about spreadsheet formula interpretation. Apostrophe prefixing is opt-in, changes text and is not represented as a universal security guarantee.

## SEO and AI search work

Unique titles and descriptions, keyword-led H1s, canonical URLs, Open Graph/Twitter metadata, visible usage instructions and FAQs, WebPage/WebApplication/BreadcrumbList/FAQPage JSON-LD matching the page, seven-item tools directory, footer-only homepage links, sitemap entries and descriptive llms.txt links. FAQ markup describes the visible content; it does not promise a Google FAQ rich result. Existing robots.txt permits public tool pages. llms.txt is a discovery summary, not a Google ranking requirement.
