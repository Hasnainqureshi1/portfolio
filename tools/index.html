About these tools

Common questions.

Each tool page explains exactly what it checks and what it cannot tell you.

Are the tools really free?

Yes. No account or payment is required. The image optimizer has file and batch limits to keep browser memory use manageable; the health check depends on Google's API availability and quota. You can optionally contact me for help with your website.

What happens to the information I enter?

The cost calculator, brief builder, image optimizer and mockup generator process your input in your browser. Neither image tool uploads your files. The health check sends the page address to Google PageSpeed Insights. Your contact details and report reach me only if you submit an optional form.

Which tool should I start with?

Budgeting a new website: the cost calculator. Ready to describe the project: the brief builder. Preparing photos for your website: the image optimizer. Presenting your website or app: the mockup generator. Unhappy with a current site's speed or search basics: the health check.
