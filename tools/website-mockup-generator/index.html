    From screenshot to presentation

    Keep your product
    in focus.

    The tool adds a visual frame to images you supply. It does not capture a URL or generate a working website.

    01 / Capture

    Start with a clear screenshot

    Capture your website in a browser or your app on a device. Remove any private information before adding the image. PNG is a useful starting point for sharp interface text.

    02 / Frame

    Match the screen shape

    Use a browser window for desktop pages and a phone or tablet for portrait screens. Choose a frame and crop position separately for each image. Showing the whole screenshot avoids cropping but can add empty space.

    03 / Arrange

    Show the important flow

    Use one screenshot to make a single screen stand out, or two to three for a product flow. Choose a style preset, then drag screens into place. Adjust size and rotation separately, or use the arrow keys for precise positioning. Add a heading and caption to explain the product.

    04 / Export

    Choose a useful file size

    Download PNG for lossless output or choose WebP quality from 50% to 100%. Transparent backgrounds work with both. For a smaller website image, run the export through the image optimizer.

    About this tool

    Common questions.

    Are my screenshots uploaded?

    No. The editor reads files you choose on your device and renders the mockup locally. Screenshots are kept in memory while this page is open. Clearing them or closing the page removes the working copy; your original files stay unchanged.

    Can I enter a website URL instead?

    No. Take a screenshot first, then add the JPG, PNG or WebP file. This tool does not fetch websites, bypass login screens or test whether a page is responsive.

    Can I use different device frames together?

    Yes. Each screenshot has its own selector for a browser, phone, tablet or no frame. Use the move buttons to change their order. The frames are original generic illustrations, not official device photographs.

    Why does part of my screenshot disappear?

    The default fill option crops an image to the frame's screen shape. Choose top, centre or bottom for the crop position, or select Show entire screenshot to keep every part visible. The tool never stretches the image.

    Can I use the export for a launch or client presentation?

    Yes. Exports have no tool watermark. Use screenshots you own or have permission to share. The demo interface graphics are examples created for this tool and are not client work.
