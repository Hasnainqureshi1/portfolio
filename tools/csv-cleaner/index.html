      A practical workflow

      How to use this tool.

      01 / Load

      Export a text CSV from your system

      Download a CSV from your spreadsheet, CRM or business application. Choose the correct text encoding and delimiter. Keep an original copy so you can reconcile the imported records.

      02 / Check

      Find structural import problems

      Check quoted fields, duplicate rows, blank rows, repeated headers and inconsistent column counts. A quoted comma is part of a field, not an extra column. Record numbers and physical line numbers can differ when fields span lines.

      03 / Review

      Apply only the fixes you need

      Choose whitespace trimming, blank-row removal and exact duplicate removal explicitly. Pad short rows only if missing fields are acceptable, or exclude inconsistent rows after review. Missing or repeated headers require editing the source.

      04 / Import

      Test the destination with a small sample

      Download the reviewed CSV and change report. The file still needs to match your destination schema and business rules. For a custom dashboard or import workflow, see custom import development.

      What it can help with

      Common questions.

      Can I map columns to an import template?

      Yes. Load destination headers, choose each source column and mark any required nonblank fields. Preview the output and download a local recipe. The tool does not infer destination data types or connect to your CRM.

      What happens to conflicting IDs?

      Choose a key column to flag every repeated-key record. Conflicting records are not automatically merged. They block the clean download unless you explicitly move them to the separate unresolved-rows file for review.

      How do I remove duplicate rows from a CSV?

      Add a CSV, select Remove exact duplicate rows, then check the file. The cleaner compares every cell after your selected fixes and keeps the first occurrence. Review the output and change log, confirm the result and download the CSV.

      What does the CSV import checker validate?

      It checks CSV quoting, expected column counts, empty or repeated headers, blank rows and exact duplicate rows. It also flags cells starting with common spreadsheet formula characters. You can also map destination headers, mark required nonblank fields and review repeated keys. It does not validate every CRM or commerce platform rule, data type or existing destination record.

      Will this fix inconsistent columns automatically?

      Only if you choose a rule. By default inconsistent rows block the CSV download. You can pad short rows with empty cells or explicitly exclude inconsistent rows. Rows with extra cells are never silently truncated. Malformed quotes must be corrected in the source.

      Does it support Excel and Google Sheets files?

      Export your sheet as CSV first. This tool accepts CSV, TSV and text files up to 5 MB, 20,000 data records and 100 columns. It does not read XLSX workbooks. CSV downloads are UTF-8 text with a BOM; no cell values are converted to numbers or dates.

      Are my customer records uploaded?

      No. File decoding, validation, previews and cleanup happen locally in your browser. Data is held in memory while the page is open. There is no account, server upload or online sharing. Download your work before leaving or reloading.

      Can I import the cleaned file straight into my CRM?

      A structurally clean CSV is a starting point. Check your CRM requirements for column names, required fields, allowed values, identifiers and date formats, then test a small import. This tool does not connect to your CRM or guarantee that a destination will accept the file.

      Why are negative numbers flagged as formula-like?

      Spreadsheet applications may interpret cells beginning with equals, plus, minus or at-sign characters as formulas. Negative numbers also match this conservative check. Review the values and choose apostrophe prefixing only if it suits the destination, because it changes the text.
