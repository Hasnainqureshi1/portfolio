ChatKnot live-chat SaaS

A real-time customer conversation platform that brings visitor activity, chat, leads, analytics and brand administration into one operational product.

ContributionFull-stack product engineeringApplicationSaaS web platformCore stackReact · Node · SQL · Redis

The product

ChatKnot helps teams see website visitors, manage conversations, retain conversation history, and turn engagement into organised leads. The product also supports multiple brands, user authentication and role-based administration.

Engineering coverage

My work crossed the product boundary rather than stopping at a single screen. The interface, API behaviour, authentication, real-time events and operational data needed to function as one coherent system.

  • React dashboard and reusable interface flows
  • Node.js and Express APIs with authentication and permissions
  • SQL-backed application data and conversation history
  • Socket.io events with Redis Pub/Sub for live communication
  • Visitor, lead and brand-management workflows

Product outcome

The result is a connected SaaS surface where live conversations and the data around them remain useful after the message is sent. Teams can move from visitor activity to conversation context, lead information and administration without disconnected tools.
